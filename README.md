# Fornax

**A GPU job queue served over MCP.** One worker on a PC with a GPU owns the card; agents and apps on other machines send it jobs (transcription, rendering, upscaling) and get the results back with a manifest.

*Fornax* is Latin for an oven, and the name of a constellation.

Status: early design. Nothing to run yet.

Related: [Tabula](https://github.com/carnaby/tabula-mcp), the memory server whose transcription worker Fornax grows out of.
